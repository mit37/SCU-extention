Import an official SCU course evaluation (PDF)

Parsed entirely in your browser — the PDF is never uploaded anywhere. We extract its text, pull out numeric rating items where we can find them, and fold the result into that professor's Likeness Score with more weight than RateMyProfessors (since these cover the whole class, not just self-selected reviewers).

Bulk-import syllabi (PDF, one or many)

Parsed entirely in your browser, nothing uploaded. Select as many PDFs at once as you want — each one is scanned for an "Instructor:" line, a course code, and a term to file it under automatically. If we can't find a professor's name in a given PDF, you'll be asked for it just for that file before it's added.

    Data

    Everything is stored locally in your browser (schedule/friends sync across your own signed-in Chrome via chrome.storage.sync; ratings cache and syllabi stay on this device).

    About the Likeness Score

    A 0–100% estimate of how much students tend to like a professor, blended from an official course-eval PDF when one's on file (40%, weighted highest since it covers the whole class), their RateMyProfessors rating (33%), "would take again" percentage (15%), ease (6% — RMP difficulty and syllabus difficulty, inverted), and syllabus policy fairness (6%), such as lenient late/attendance policies vs. strict no-exceptions ones. Any signal that's missing drops out and the rest reweight, so a professor with only an RMP rating still gets a sensible score. Confidence is lower when a professor has few ratings and no evals/syllabi on file.
